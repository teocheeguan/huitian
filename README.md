# 惠田水超市多门店库存管理系统

惠田水超市的多门店库存和桶账系统。Python 标准库提供 HTTP 服务，SQLite 存储单据和流水，浏览器使用原生 HTML、CSS 和 JavaScript，无需 Node.js 或 pip 安装依赖。

## 在新电脑接手

```bash
git clone https://github.com/teocheeguan/huitian.git
cd huitian
```

已克隆的工作副本可以用 `git pull --ff-only` 同步。开发环境建议使用与生产一致的 Python 3.12。在新电脑或新的 AI 工具里打开仓库根目录，先读 [AGENTS.md](AGENTS.md) 和 [维护交接](docs/MAINTENANCE.md)。

## 第一次使用

1. Mac 双击 `start-mac.command`，Windows 双击 `start-windows.cmd`。也可以在解压目录运行 `python3 -B app.py start`，Windows 使用 `py -3 -B app.py start`。
2. 首次启动时，在终端输入两遍你设置的密码，至少 12 个字符。管理员账号为 `admin`。终端输入密码时不会显示字符。
3. 网页会自动打开。也可以访问 [本机库存系统](http://127.0.0.1:8765)。运行时请保持服务进程开启。
4. 在「基础设置」新增门店与对应门店账号。进入「商品管理」建立商品，填写统一的品牌和规格。
5. 在「进销管理 → 添加进货商品」录入各门店实际结存或到货数量。先核对实时库存，已有结存的商品按实物盘点校准数量。

Mac 如限制双击执行，在解压目录打开终端运行 `python3 -B app.py start` 即可。Windows 若 `py` 命令不可用，可在安装 Python 后用 `python -B app.py start`。

## 日常操作

| 事项 | 操作方式 |
| --- | --- |
| 销售下单 | 在「订单管理」选择门店并下单。从商品目录添加商品，填写数量。订单确认后扣减所选门店的对应库存，并生成销售单据。 |
| 实收空桶 | 单内有桶装水时，按实际品牌及规格填写实收空桶；没有则勾选「本单实收空桶为 0」。实收空桶进入该店库存。 |
| 进货 | 在「进销管理 → 添加进货商品」选商品、数量和分配门店。确认后增加所选门店库存并保存日期和进货单。 |
| 商品 | 分类为桶装水、空桶系列、瓶装水、其他。总部可删除零库存商品，已记账的流水和单据保留。有关联在售桶装水的空桶需先处理其关联商品。 |
| 调货 | 实物交接时由调出门店或总部填单确认，两店库存同一笔记账。 |
| 盘点 | 在「库存管理 → 盘点」输入实盘数量，系统自动记录盘盈或盘亏。 |
| 退货与错单 | 实际退货从原销售单填写实退数和可再次销售数；录错走冲销，原记录保留。 |
| 看板 | 日期使用北京时间。库存及订单总数按统计日截止。应回桶、实回桶和差回空桶按当日统计，可选日期查历史。 |

桶装水和空桶以品牌与规格关联。差桶在门店和桶型范围内计算，实收其他品牌或规格时分别记入空桶库存。原有库存、历史单据及旧客户和押桶账继续留存，日常下单无需客户联系电话、订单来源或原订单号。

## 总部与多门店共同使用

正式使用时，各店用浏览器访问同一个 HTTPS 地址，并用各自的门店账号登录。业务记录由服务器上的 SQLite 数据库统一保存。开发用的本机数据库与门店账套各自独立。

反向代理、子路径、数据库备份和升级步骤见 [部署和回滚](deployment/DEPLOY.md)。

## 测试与备份

如需先试用示例账，可单独创建一个演示数据库。演示账号为 `demo`，密码由你设置。

```bash
python3 -B app.py --db data/demo.sqlite3 demo
python3 -B app.py --db data/demo.sqlite3 serve --port 8766
```

打开 [本机演示账](http://127.0.0.1:8766)。演示库和正式库分别保存在不同文件中。

```bash
python3 -B -m unittest -v
python3 -B app.py backup backups/huitian-backup.sqlite3
```

备份命令从正在使用的数据库生成独立副本，目标文件须为新文件名。恢复时先停止服务，保管原数据库和同目录的 WAL、SHM 文件，然后用已验证的备份路径作为 `--db` 重新启动，检查后再切回正式入口。
